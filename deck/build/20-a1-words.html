Words used in this deck.

Vendor — An outside company that sells software to a company. Example: Trissino.
Integration — A connection that lets one piece of software read data from another.
API — The “door” software uses to talk to other software.
OAuth — The “allow this app” button. It creates a key the app uses.
Scope / permission — What the key is allowed to see or do.
Admin-level app — One admin says yes for the whole company. The app sees everyone.
User-level app — Each person says yes for themselves only.
Bring your own OAuth — The company uses its own app keys. It keeps more control.
Proxy — Something in the middle that passes messages on. Gatekeeper also filters.
Audit log — A record of every request: who asked, for what, what was sent.
IT / security team — The people who decide which tools can access data.
MCP — A standard way for AI assistants to plug into other software.
